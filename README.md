# Maui · Ocean View — Leo’s trip site

Self-contained single page. No build step.

## Open

```bash
# From this folder, any of:
open index.html          # macOS
xdg-open index.html      # Linux
start index.html         # Windows
```

Or serve locally:

```bash
python3 -m http.server 8080 --directory /workspace/hawaii-trip
# then visit http://localhost:8080
```

Files: `index.html` + `styles.css` (Google Fonts CDN only).

Prices are **snapshots as of Oct 6, 2026 PT** — re-check before booking.
